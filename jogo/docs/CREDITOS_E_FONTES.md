# Credits and sources

## Project

Adventure Time: O Portal da Amizade. Unofficial academic fan-game asset pack based on the user's supplied SGDD for Quest III, UNIFOR. Adventure Time character names and settings are existing franchise material; no official affiliation is claimed.

## Visual assets

Artwork generated with the built-in image-generation tool, using production prompts for six characters, six backgrounds, six terrain/decor kits, object atlases, interface kit, effects and story illustrations. The final ending image was corrected to show six crystals. The full prompt set is `image_generation_prompts.json`.

High-resolution sources are retained in `Source_Sheets`. Game-ready derivatives were automatically cropped, aligned and resized with nearest-neighbor sampling; generated transparency was preserved. Typography, keycaps, contact sheets and catalogue layouts were assembled programmatically. This pack is AI-assisted artwork, not a claim of hand-drawn pixel animation.

## Audio

Eight original procedural chiptune arrangements and 28 synthesized sound effects created for this package. No show soundtrack, voice lines, commercial samples or downloaded recordings were used.

## Verification limits

Files, dimensions, alpha presence, animation references, Godot resource loading, wave structure, signal levels and archive integrity were checked. Asset previews were visually inspected. The user's actual game project and physical controller were not supplied; no complete-game or hardware validation is claimed. Audio signal checks are not a substitute for a listening test on the presentation equipment.

## Revision 2
Six new eight-pose walk sheets and a targeted Marceline passing-pose correction used the built-in image-generation tool. Revision prompts and originals are retained. Existing other character poses were preserved with revised sequencing, anchors, padding and timing. Playable movement and state-transition tests were added.
